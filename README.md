# Talent Acquisition

Two-player competitive social stealth game. You and a rival alien are disguised as office workers — blend in, quietly abduct the staff, and eliminate your opponent before they do the same to you.

Built with Godot 4.6.1 (C# / Mono).

## Concept

Corporate headhunters from rival galactic empires, all disguised as mundane office workers, dropped into a single Earth office building. Linger near human NPCs to secretly acquire them, or tag the opposing alien directly. Sprinting exposes your true form — use it sparingly.

## Controls

| | Player 1 | Player 2 |
|---|---|---|
| Move | WASD | Arrow Keys |
| Sprint | L-Shift | R-Shift |
| Tag | Space | Enter |
| Pause | Esc | Esc |

## Modes

- **Tag Only** — first to tag the rival alien wins.
- **Quota Mode** — acquire 5 NPCs by proximity upload to win, or eliminate the rival outright.

## Requirements

- [Godot 4.6.1](https://godotengine.org/) with .NET / C# support
- .NET 8 SDK

## Run

Open `project.godot` in Godot 4.6.1 and press F5.
